📖 使用说明

这是什么
把你的论文/文稿，变成"评委爱听的答辩 PPT 框架"——不做排版，只做汇报逻辑。

怎么用
1. 粘贴论文/文稿内容 → 2. 设定汇报时长 → 3. 点「开始生成」
4. 看 Agent 工作过程（萃取→重构→评审→循环）→ 5. 复制最终框架

Agent 会做什么（4 个角色）
① 萃取：读懂论文，提炼核心观点/数据/结论
② 重构：按"结论先行 + 金字塔结构"生成初稿
③ 评审：自己检查缺背景/缺数据/字数超标/时长不符
④ 重生成：按评审意见修改，循环直到达标（最多 3 轮）

第一次使用
1. 首次打开会弹出「👤 偏好」——填你的专业和听众偏好，Agent 会一直记住（Memory）
2. 点右上角 ⚙️ 设置 → 填 Cloudflare Worker 地址 → 保存 → 测试连接
